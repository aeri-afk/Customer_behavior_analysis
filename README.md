# Customer Behavior Analysis

This project analyzes customer purchasing behavior to uncover valuable business insights and trends. Using SQL, Python, and Power BI, the dataset was cleaned, transformed, and analyzed to understand customer demographics, spending patterns, and purchasing habits.

## Objectives

* Analyze customer purchasing behavior and trends.
* Identify high-value customers and spending patterns.
* Measure key performance indicators (KPIs) such as total sales, average purchase value, and customer retention.
* Create interactive dashboards for data-driven decision-making.

## Tools & Technologies

* SQL for data extraction and querying
* Python (Pandas, NumPy, Matplotlib) for data cleaning and analysis
* Power BI for dashboard creation and visualization
* Excel for data preparation

## Key Insights

* Customer segmentation based on purchasing behavior.
* Analysis of demographic factors affecting sales.
* Identification of top-performing customer groups.
* Visualization of sales trends and business performance metrics.

This project demonstrates practical skills in data cleaning, exploratory data analysis (EDA), KPI development, data visualization, and business intelligence reporting.
