# 📊 Customer Behavior Analysis

## Project Overview
This project analyzes customer purchasing behavior using SQL, Python, and Power BI. The goal is to identify purchasing trends, customer segments, and key business insights that support data-driven decision-making.

## Tools & Technologies
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- Excel

## Key Objectives
- Analyze customer purchasing patterns
- Identify high-value customer segments
- Track important business KPIs
- Discover spending trends and demographics
- Create interactive Power BI dashboards

## Project Workflow
1. Data Collection
2. Data Cleaning & Transformation
3. Exploratory Data Analysis (EDA)
4. KPI Calculation
5. Dashboard Development
6. Business Insights & Recommendations

## Key Insights
- Customer spending patterns were identified.
- Demographic trends were analyzed.
- Revenue-driving customer groups were highlighted.
- Interactive dashboards improved data visualization.
